Репозиторий по полугодовому курсу C#. Сушкой Андрей Сергеевич, КБ-251, 2 курс, "Промышленное программирование".

Проект предназначен для обработки специализированных наборов генетических данных: считывает данные о белках и организмах, декодирует аминокислотные цепочки, сжатые с помощью алгоритма RLE, и выполняет пакетную обработку команд из текстового файла.
